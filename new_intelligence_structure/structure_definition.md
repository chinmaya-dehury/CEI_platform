# Intelligence Structure Definition

This document defines the parameters used in the `intelligence_structure.json` schema.

## `metadata` (Object, REQUIRED)
Contains the core identifying and contextual information about the intelligence source.

- `id` (String, REQUIRED): A unique identifier assigned to an intelligence generated by an agent.
- `name` (String, REQUIRED): A human-readable name describing the intelligence.
- `description` (String, OPTIONAL): A brief explanation of what the intelligence represents.
- `version` (Integer, REQUIRED): Schema or configuration version number (e.g., 1).
- `agent` (Object, REQUIRED): The edge agent responsible for generating the intelligence.
  - `id` (String, REQUIRED): A unique identifier of the edge agent.
  - `type` (String, REQUIRED): Indicates whether the edge agent is deployed at a fixed location or is mobile. (Allowed values: `fixed_location` or `mobile`).
- `domain` (String, REQUIRED): The broader application area to which the intelligence belongs.
- `context` (String, OPTIONAL): Describes the situation in which the intelligence applies.
- `tags` (Array of Strings, OPTIONAL): Keywords used to classify, discover, filter, or subscribe to intelligence.
- `source` (String, REQUIRED): The endpoint or reference through which the intelligence can be accessed.
- `status` (String, REQUIRED): The current availability of the agent providing the intelligence. (Allowed values: `online` or `offline`).
- `update_mode` (String, REQUIRED): Defines how the intelligence is generated or updated. (Allowed values: `periodic`, `event-driven`, `on-demand`).
- `frequency` (Object, REQUIRED if update_mode is periodic, otherwise OPTIONAL): Defines the expected interval at which intelligence (periodic) is updated.
  - `value` (Integer, REQUIRED): The numeric interval value.
  - `unit` (String, REQUIRED): The time unit. (Allowed values: `sec`, `min`, `hr`, `mth`, `yr`).

## `intelligence_items` (Array of Objects, REQUIRED)
The current intelligence generated by the edge agent.

- `intelligence` (String or Numeric, REQUIRED): The actual insights generated by the edge agents.
- `generated_at` (Datetime String, REQUIRED): The data and time at which the intelligence was generated.
- `valid_until` (Datetime String, OPTIONAL): Defines how long the generated intelligence remains usable.
- `location` (Object, OPTIONAL): The geospatial coordinates relevant to this specific data point.
  - `latitude` (Numeric, REQUIRED if location is present): Latitude coordinate.
  - `longitude` (Numeric, REQUIRED if location is present): Longitude coordinate.
